## Notes

**On the MSPbots naming decision:** The brand name is used freely in body copy and will carry into alt text when that section is completed. It was intentionally kept out of the meta title and description — it carries no meaningful search volume and doesn't serve the primary SEO goal of attracting prospects and recruiters. The deliverable type ("UI design guidelines," "HTML templates") does that work instead.

**On the meta description:** Tone is neutral and factual per case study guidelines. "Adopted and applied on day one" is the anchor outcome — it's specific, credible, and signals immediate value without overstating. At 145 characters, there's a small buffer if you want to add a second outcome (e.g. "follow-up project requested by the team") — that would land at approximately 199 characters, which exceeds the limit, so the current version is cleaner.

**On image alt text:** Pending updated HTML with official captions. When provided, note that decorative/UI elements (selector-box, orange-dot, chevrons, pin points, plus, heart-point, breadcrumb-divider) should carry `alt=""` — they add no SEO value and empty alt correctly signals to screen readers that the image can be skipped.
